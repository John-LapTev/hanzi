Аудиозаписи произношения для приложения hanzi.

Синтезированы один раз через Gemini TTS (сервис Media Flow), голос Kore, язык zh-CN,
и сохранены как обычные файлы. Приложение их только проигрывает: во время работы
никакие сервисы не вызываются, интернет не нужен.

Имя файла — первые 16 символов sha1 от фразы. Соответствие «фраза → файл» лежит в index.json.
