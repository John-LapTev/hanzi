# hanzi

Офлайн-приложение для изучения китайского языка. Интерфейс на русском, данные хранятся только
в браузере, интернет не нужен.

**Открыть:** https://john-laptev.github.io/hanzi/

Слова с примерами, шесть режимов тренировки, интервальные повторения (SM-2), озвучка,
порядок черт, разбор порядка слов и разговорные сценки.

Чистые HTML, CSS и JavaScript без сборщиков и зависимостей. Данные о порядке черт —
из проекта Make Me a Hanzi, лицензия в `data/LICENSE-strokes.txt`.
